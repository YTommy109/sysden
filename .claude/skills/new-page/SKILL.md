# /new-page — 画面追加

新しい画面を追加するとき、ルーター・テンプレート・E2E テストの 3 点セットを漏れなく作成する。

## 引数

```
/new-page <page_name> — <画面の説明>
```

例: `/new-page settings — アプリ設定画面`

## 手順

[docs/coding_rule.md の画面追加手順](../../../docs/coding_rule.md#画面追加手順)に従って実施する。
